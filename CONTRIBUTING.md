# Участие в проекте

**Проект находится в статусе сырого прототипа (бета).** Это значит, что API, структура модулей и баланс меняются свободно, а часть механик не доделана. Пожалуйста, учитывайте это.

## Перед началом

- Крупные изменения (новая механика, переписывание рендера, смена формата сейва) сначала обсудите в issue.
- Мелкие исправления и опечатки можно присылать сразу Pull Request'ом.

## Требования к коду

- **Без зависимостей.** Проект принципиально живёт без npm-пакетов и без сборки.
- **Без внешних ассетов.** Вся графика и звук генерируются кодом в `textures.js`, `sprites.js`, `audio.js`. Не добавляйте PNG, WAV и шрифты.
- **Чистые модули — чистые.** Логика в `rng.js`, `combat.js`, `economy.js`, `contracts.js`, `run.js`, `wildlife.js`, `npc.js`, `weather.js`, `dither.js`, `lighting.js`, `motion.js`, `ray.js`, `world.js` не должна трогать `window`, `document` и `localStorage`. Иначе её нельзя протестировать в Node.
- **Детерминизм.** Случайность только через `src/rng.js`. `Math.random` в игровой логике ломает сохранение и воспроизводимость.
- **Стиль.** Модули ES, двойные кавычки, точки с запятой, отступ 2 пробела. Комментарии и пользовательские строки — на русском.

## Перед отправкой

```bash
npm run verify
```

Команда проверяет синтаксис всех модулей и гоняет unit-тесты. Если меняли рендер — приложите скриншот: логические тесты не ловят визуальные регрессии.

## Тесты

Новая чистая логика должна идти с тестами в `tests/`. Смотрите на существующие файлы как на образец: `systems.test.js`, `controls.test.js`, `graphics.test.js`, `weather.test.js`, `wildlife.test.js`, `ray.test.js`.
