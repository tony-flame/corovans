# Публикация на GitHub

Репозиторий подготовлен: коммит сделан, рабочее дерево чистое. Осталось создать репозиторий на GitHub и запушить.

## Вариант 1 — через сайт (без установки чего-либо)

1. Откройте <https://github.com/new>
2. **Repository name:** `corovans`
3. **Description:** скопируйте из `gh-description.txt` (в этой же папке) или из блока ниже
4. **Public**, **не** ставьте галочки на README / .gitignore / License — они уже есть
5. Нажмите **Create repository**
6. В папке проекта выполните:

```powershell
git -c safe.directory=E:/Corovans remote add origin https://github.com/ВАШ_ЛОГИН/corovans.git
git -c safe.directory=E:/Corovans push -u origin main
```

## Вариант 2 — через GitHub CLI (если установите)

```powershell
winget install GitHub.cli
gh auth login
cd E:\Corovans
gh repo create corovans --public --source=. --remote=origin --push --description "Сырой прототип (бета) браузерного рейкастера в духе Daggerfall"
```

## Описание репозитория (Description)

Короткое, для поля «Description» в GitHub (лимит 350 символов):

```
Сырой прототип (бета) браузерного рейкастера в духе Daggerfall. Псевдо-3D от первого лица, деревня, тракт, караваны. Vanilla JS + Canvas 2D, без сборки и зависимостей. Вся графика и звук генерируются кодом.
```

## Topics (теги репозитория)

Добавьте в настройках репозитория, тег «About» → шестерёнка:

```
raycaster  canvas  game  daggerfall  vanilla-js  procedural-generation  prototype  beta
```

## Что сделать после публикации

1. **Settings → General →** убедитесь, что **Releases** включены (по умолчанию включены).
2. **Releases → Draft a new release**, тег `v0.1.0-beta`:
   - Название: `0.1.0-beta — первый публичный прототип`
   - Описание: см. блок ниже
3. Проверьте, что скриншоты в README отображаются (они лежат в `docs/screenshots/`).
4. Pin репозиторий в профиле, если хотите.

## Текст для первого релиза

```markdown
Первый публичный прототип. Это **бета**: играть можно, но баланс не отлажен,

**Проверка:** `npm run verify` — 109 тестов.

Известные ограничения перечислены в README.
```
